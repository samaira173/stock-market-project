# StockSense

Stock market analytics dashboard built using:

- HTML
- CSS
- JavaScript
- Node.js
- Express
- Python
- yfinance

## Features

- Company search
- Ticker search
- Live stock data
- Moving averages
- Volatility calculation
- Python analytics backend
