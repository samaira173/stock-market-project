# StockSense

A stock market web application focused on portfolio tracking, market insights, and learning through data.

## About The Project

StockSense is an open-source project being built during the Open Source Hackathon 2026.

The goal is to create a web application that allows users to explore stock market data, track portfolios, analyze trends, and gain useful insights through data analytics and machine learning.

This project combines my experience with Python, data analysis, and machine learning with my goal of learning modern full-stack web development. Throughout the hackathon, I plan to build and deploy a complete application while exploring technologies such as Node.js, authentication systems, databases, and cloud deployment.

StockSense is also a personal challenge to step outside my comfort zone, learn new technologies, and improve my full-stack development skills by building a real-world project from idea to deployment within one week.

## Planned Features

* Stock market data visualization
* Portfolio tracking
* User authentication
* Google and GitHub sign-in
* Email/password account creation
* Personalized dashboards
* Historical portfolio tracking
* Market trend analysis
* Machine learning powered insights
* Guest mode with local storage support
